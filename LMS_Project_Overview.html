1. Project Snapshot

🏗️ What Is This Project?

A LMS Loan Management System managing members, loans, deposits (FD/RD), thrift savings, share capital, receipts, payments, and monthly salary recovery.

Originally built on Sybase + old Java (legacy system — 37 tables, 81 stored procedures). Now being upgraded to modern Spring Boot + React.

📦 Tech Stack

Spring Boot 3.5 Java 21 MySQL 8.0 Spring Security JWT Auth JPA / Hibernate Lombok React + Vite iText PDF
